# YT Monetize - Standalone Admin Panel

এই ফোল্ডারে অ্যাডমিন প্যানেলের সমস্ত স্বয়ংসম্পূর্ণ ফাইল রয়েছে:
- `index.html` : মূল অ্যাডমিন ইন্টারফেস
- `app.js` : ফায়ারবেস ফায়ারস্টোর ও ImgBB ইমেজ আপলোড লজিক
- `style.css` : প্রিমিয়াম রেসপনসিভ ডিজাইন ও স্টাইল
